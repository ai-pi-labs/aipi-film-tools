## 逐镜工作台

![《归雾镇》第一集 · 逐镜工作台](case-workbench-preview.png)

工作台保持一镜一行，每镜展示时间范围、时长、关键帧、画面观察、对白、导演分析与复拍建议。导演分析包括人物意图、情绪变化、视线与空间、切镜理由，方便从画面表现追溯创作选择。

- **播放跟随**：当前镜头随视频高亮，表格自动滚动到对应位置。
- **点击定位**：点击镜头跳转到原片相应时间，快速回看细节。
- **搜索查找**：按镜号、对白或导演建议检索，关键帧支持放大。
- **暂停细读**：手动滚动时暂缓跟随，便于阅读长对白和分析；跨镜句子在相关镜头保留全文。

## 打开方式

1. 下载并完整解压 `aipi-guiwu-episode01-case.zip`。
2. 进入 `aipi-guiwu-episode01-case/` 文件夹，打开 `report.html` 查看工作台。
3. 用视频播放器打开 `AIπ同步审片-参考版.mp4`，或用表格软件打开 CSV 查看逐镜记录。

请保持文件夹结构，确保工作台能读取同目录的原片和关键帧。查看交付成果无需安装技能。

如果浏览器无法直接播放本地视频，在解压后的文件夹中运行：

```sh
python3 -m http.server 8000
```

然后打开 `http://127.0.0.1:8000/report.html`。

需要核对下载文件时，在同时保存 ZIP 和 `.sha256` 的目录运行：

```sh
shasum -a 256 -c aipi-guiwu-episode01-case.sha256
```

## 使用说明

可用工作台逐镜学习，用 CSV 整理制作批注，用同步视频开展看片讨论，再结合导演分析与复拍建议制定拍摄方案。

台词与唱腔仍有待核内容，定稿前请结合原片确认。具体标记见工作台和随包记录。
