**视频来源：饭团鱼子酱（钱叔_）提供。** AIπ（AI圆周派）提供逐镜拉片工具、导演分析、复拍建议和同步审片导出。

这里直接提供此前测试的《归雾镇》第一集成果。原片、逐镜数据、报告、字幕、表格、关键帧和同步视频均沿用已有文件，未重新生成案例或重编码视频。

## 下载后怎么用

完整解压 `aipi-guiwu-episode01-case.zip`，进入 `aipi-guiwu-episode01-case/` 文件夹：

| 文件 | 用途 |
| --- | --- |
| `report.html` | 打开播放联动工作台 |
| `原片.mp4` | 本次测试使用的原始视频 |
| `AIπ同步审片-参考版.mp4` | 直接播放已导出的同步审片视频 |
| `study.json` | 93 镜、74 条语言事件及审核状态，可继续复核 |
| `逐镜导演分析.csv` | 一镜一行的镜头表与导演记录 |
| `完整逐句字幕.srt` | 现有 74 条语言记录的字幕导出，准确性以审核状态为准 |
| `frames/` | 双帧图片与帧图清单 |
| `CASE-README.md`、`verification.json`、`SHA256SUMS` | 来源、已知边界、验收摘要与文件指纹 |

保持目录结构即可整体移动。若浏览器限制本地媒体，在解压后的案例目录运行：

```sh
python3 -m http.server 8000
```

再打开 `http://127.0.0.1:8000/report.html`。该案例包是成品素材，不需要当作技能安装；只查看结果也不需要重新运行分析或同步导出。

校验下载时，在同时存放 ZIP 和 `.sha256` 的目录运行：

```sh
shasum -a 256 -c aipi-guiwu-episode01-case.sha256
```

其他系统可用 SHA-256 工具，将 ZIP 摘要与校验文件比较。

## 验证结果与仍待核的内容

本次公开整理检查了 ZIP 完整性、移动解压后的全部文件指纹、报告相对资源、内嵌数据、186 张帧图、93 行镜头记录及 74 条字幕。原片与同步视频的 SHA-256 均匹配此前整集验收记录；现有成品文件字节未变。

此前同步验收确认 5104 帧，并通过 185 个镜头首末帧采样检查（单帧镜仅采一次，并非 185 个独立切点），解码后的原声音频信号一致。历史图像比对覆盖镜号和标题区域，正文与交互的检查范围见包内验收文件。本次整理引用这些历史验收结果，没有重新听审全片；技术同步通过不等于全部语言内容已确认。

声音审核仍为 `partial`，生产检查不通过。已知事项包括：

- D005：无字幕唱腔的词句及边界待核。
- D051：可见字幕已核，口述代词及设备正式名称仍待确认。
- D012、D020、D041：短应答说话人含上下文推断。
- D060–D067：来自原片标注的“戏曲大意”，不能当作逐字唱词。
- 全音轨的人工复听尚未完成。数据中的部分历史核对说明引用了 `证据/audio-windows.json`，该原始过程文件未随公开包提供。

现有文件名中的“完整逐句字幕”表示该次数据的逐句导出，不代表每句已通过完整音轨听审。继续用于内容生产时，应先补核以上事项及声音覆盖记录。
