# 开发与验证

仓库使用 Node.js 标准库和外部媒体工具，没有 npm 运行依赖。完整测试要求 Node.js 22+。

```sh
npm test
npm run test:ui -- --chrome /path/to/chrome --artifacts work/ui-check
npm run test:sync -- --out work/sync-check
npm run package
```

同步测试的浏览器位置可通过 `AIPI_CHROME` 指定。测试会现场生成合成视频；素材和浏览器配置都写到忽略的生成目录。可选 UI 实片测试传入 `--study /path/to/study.json`，会根据数据动态选择检查镜头。

## 检查范围

- 核心引擎：真实帧时间、一帧镜、VFR、非零PTS、跨镜全文与独立字幕、不完整声音阻断、素材与帧图身份、补切与重编号。
- 网页：响应式布局、长中文内容、播放与跳转、跟随控制、搜索、片尾与来源状态。
- 同步：横竖画幅、精确帧数、单帧卡片匹配、完整原声、真实正文越界、输入及实现文件快照。
- 打包：ZIP根目录、独立许可证、文件指纹、可重复构建，以及实际解压后的入口执行。

GitHub Actions 的默认任务执行核心引擎、报告契约和打包检查。需要浏览器的回归在配置好浏览器后本地执行；默认 CI 通过不代表这些浏览器项目在所有系统均通过。

## 内容状态

生成候选、填入记录、完成内容核对是不同步骤。`verified` 仅指向实际核对的数据来源；`source=subtitle` 不能冒充音轨听审。语言审核覆盖必须有真实依据，不能通过删除对白并改写状态使生产检查通过。

变更切点、对白或导演内容后重新生成报告和同步视频。更新面板实现后重新编码，保持输出与代码一致。对长文字应调整版式或尺寸，不删减原文。
