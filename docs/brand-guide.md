# AIπ · 项目首页规范

AIπ 的中文名称为 **AI圆周派**。各项目共用品牌头图和首页结构，项目名称、功能说明、安装方式与案例按实际内容填写。

## 品牌头图

使用 [aipi-banner.svg](assets/aipi-banner.svg) 作为模板，复制到项目的 `docs/assets/aipi-banner.svg`。

- 保留 AIπ 与 AI圆周派标识、居中版式和边框线条。
- 炭黑背景 `#171b20`，金色强调 `#efb760`，主文字 `#f4f5f7`，次文字 `#a9b2bd`。
- 左上角固定为 `AI-PI-LABS`；右上角和底部三项文字替换为本项目的领域与能力。
- 头图使用仓库内相对路径，提供简短且有意义的替代文字；不依赖外部字体或脚本。

## 首页顺序

1. 品牌头图、项目名、一句定位。
2. 真实的版本、许可或能力徽章。
3. 简体中文 / English 切换。
4. 安装、下载、案例、使用入口。
5. 现成效果或可直接观看的演示。
6. 核心能力、最短安装步骤和可复制调用示例。
7. 可展开的高级用法、开发命令与验证记录。
8. 原有署名、来源与许可说明。

```html
<p align="center">
  <img src="docs/assets/aipi-banner.svg" alt="AIπ · AI圆周派 — 项目用途" width="100%">
</p>

<h1 align="center">AIπ · 项目名称</h1>
<p align="center"><strong>一句话说明项目解决什么问题。</strong></p>
<p align="center"><strong>简体中文</strong> · <a href="README.en.md">English</a></p>
```

`README.en.md` 应提供完整的项目说明和安装入口，并链接回 `README.md`。导航只链接实际存在的文档、附件或有效章节；没有 Release、许可或演示时，不创建占位徽章或虚构内容。

## 展示与文案

使用项目已有的真实案例。GitHub 视频附件 URL 单独占一段即可呈现原生播放器；节选注明时长，并提供完整交付入口。示例代码、提示词和数据同样可以作为展示内容，不强行为每个项目制作视频。

首页说明读者能得到什么、怎样开始和如何使用。内部过程和细碎验收记录放入对应文档，影响使用的限制简短保留。素材来源用中性备注；原作者署名和许可证按项目原有规定保留。

私有仓库使用本地徽章，避免把仓库名或状态传给外部徽章服务。公开仓库可使用真实 Release 徽章。品牌统一不改变仓库可见性，也不改变软件或素材的许可。
