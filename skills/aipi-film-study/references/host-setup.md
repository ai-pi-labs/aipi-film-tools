# 宿主与依赖

本技能使用Node.js标准库调用FFmpeg及ffprobe。先在当前宿主命令环境中检查这些工具，而不是根据另一应用可运行就推定本应用也能找到。

WorkBuddy可通过“技能→添加技能→上传技能”导入本技能ZIP，在已安装列表中启用。导入器管理安装目录；执行时从实际加载的SKILL.md位置解析脚本路径。

视觉理解、语音转写、字幕读取和人工核对属于工作流所需的宿主能力，不会因导入此包而自动获得。缺少能力时保留待核状态；用户素材只在其授权的工作目录内处理。需要联网服务时按用户选择的服务及授权范围使用，不由本技能自行上传原片。

首次使用先运行engine.mjs --help及附带测试，再用短素材生成底稿、参考帧和网页并实际打开检查。HTML是普通浏览器页面，无外部网页字体或在线脚本依赖。Windows及其他平台的可用性以各自实际运行结果为准。
