# AIπ｜AI圆周派 · 同步审片

根据 `aipi.film-study/v1` 数据和对应原片生成同步视频。它不替代影片分析；缺失的对白或导演内容应在拉片数据中补全，再导出。

## 首次使用

用当前技能所在文件夹作为 `{skill}`。确认当前宿主可调用Node.js 22或更高版本、FFmpeg、ffprobe及Chrome/Chromium。浏览器用于生成独立的静态信息面板，不接管用户正在使用的窗口。准备能显示中文的字体。

首次在 Codex、Claude Code、WorkBuddy 或其他宿主运行时先读 [安装与宿主检查](references/host-setup.md)。安装技能不会自动安装这些工具，云端执行环境也不会直接继承本机依赖。

## 导出流程

1. 检查输入数据和视频确属同一素材；确认切点连续、参考帧有效、逐句引用完整。已确认的恒定帧率应使用源帧索引，不能把两位小数当成精确帧边界。
2. 默认导出生产检查：
   `node "{skill}/scripts/export.mjs" study.json --video "原片.mp4" --out "同步审片.mp4" --work "中间文件夹"`
   声音审核未完成、仍有待核条目、文字或关键文件缺失时不得报告通过。
3. 当需要查看尚未核完的数据时，显式使用 `--reference`，输出必须显示“参考版／含待核项”。参考导出不能替代生产检查或把未确认的内容改成已审核。
4. 如自动发现浏览器失败，使用 `--chrome "浏览器可执行文件完整路径"`。其他参数以 `--help` 为准。

当前实现以独立的逐镜信息面板生成同步画面，按源帧数精确保持每镜持续时间。完整原片按自身时间播放，不为了读完文字而延长镜头。短镜可暂停细读。画幅按方向排布，主体不裁切；全文放不下时应明确报错或调整面板空间，不能截字或删除句子。

当前逐帧合成路线要求零起点的恒定帧率素材，并核对实际帧时间；对不满足条件的可变帧率或非零起点素材明确停止，先在独立副本规范时间轴后重新分析，不能静默改速后套旧切点。

## 交付验收

完整解码导出文件，核对视频帧数、片长、画幅和音轨；按源帧号抽取一帧镜及前后帧。检查最长对白、最长导演文字、跨镜续句和片尾。每次检查应能看到实际成片的最后一句和最后一条复拍建议，不能只看输入JSON。

源音轨可直接保留时核对复制结果；音频信号一致不代表声音转写已经完整。报告真实技术验收与内容审核两种结果，待核内容持续保留在数据、界面和成片中。

输出MP4和检查清单，并记录输入数据与视频的身份。修改镜头、对白或面板后重新导出，避免沿用旧图。跨平台运行需要当地字体和工具检查；不能将本机测试泛称所有操作系统已验证。
